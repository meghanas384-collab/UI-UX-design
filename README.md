# Personal Portfolio UI/UX Design

## 📌 About the Project

This project is a personal portfolio website designed as part of my beginner-level UI/UX design internship.

The main goal is to create a clean, modern, and user-friendly portfolio that showcases my skills, projects, education, and experience.

## 🎯 Objective

- Create a professional personal portfolio
- Apply basic UI/UX design principles
- Create a simple and easy-to-use navigation
- Design responsive layouts for different screen sizes
- Practice wireframing and prototyping using Figma

## 🛠️ Tools Used

- Figma
- Canva
- GitHub

## 🎨 Design Features

- Modern and minimal UI
- Clean typography
- Consistent colors
- Responsive design
- Simple navigation
- Interactive prototype
- Project showcase
- Contact section

## 📱 Screens Designed
